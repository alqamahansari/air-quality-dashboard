# Air Quality Dashboard  
This repository contains an Air Quality Analysis and Dashboard project developed during a short-term Data Analytics internship using Power BI.

## Project Objective   
The goal of this project was to analyze air quality trends across cities and monitoring stations and generate interactive dashboards for better environmental insights and decision-making.

## Features   
- Air quality trend analysis
- City-wise and station-wise comparisons
- Interactive Power BI dashboards
- Data cleaning and preprocessing
- KPI and visualization reporting

## Tools & Technologies   
- Power BI
- Python
- Pandas
- CSV Datasets

## Datasets Used  
- city_day.csv
- city_hour.csv
- station_day.csv
- station_hour.csv
- stations.csv
